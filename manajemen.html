Status Sistem Real-Time (Firebase)

Control Center Ousevoid terhubung secara real-time menggunakan Google Firebase Cloud DB. Setiap perubahan data produk, harga, stok, maupun voucher promo akan langsung tersinkronisasi ke tampilan toko pengunjung tanpa penundaan.

Standar Operasional Prosedur (SOP) Manajemen

1. Katalog & SKU Varian

Pastikan nama produk, harga, dan stok diinput presisi. Jika produk memiliki varian tipe/warna, wajib isi SKU varian agar pelanggan dapat memilih opsi pada halaman detail.

2. Verifikasi Pembayaran

Semua transaksi di checkout diatur dengan proteksi 1x klik. Pesanan hanya akan dicatat sah dan diverifikasi apabila callback otomatis Midtrans menyatakan status pembayaran lunas.

3. Pelayanan CS (Tiara)

Sesi Live Chat memakai ID unik per perangkat. Tanggapi keluhan pelanggan dengan ramah. Setelah selesai, tekan tombol 'Selesaikan Sesi' agar percakapan terarsip otomatis.

4. Keamanan & Database

Dilarang menyebarkan kata sandi maupan PIN rahasia admin. Semua riwayat transaksi disimpan di Firebase Firestore sesuai kepatuhan perlindungan data pribadi (UU PDP).
